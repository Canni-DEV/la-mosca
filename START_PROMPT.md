# Prompt recomendado para comenzar la implementación

Usar en Cursor Agent desde la raíz del repositorio:

```text
Implementá la Fase 1 de La Mosca siguiendo las instrucciones de AGENTS.md, las reglas aplicables de .cursor/rules y toda la documentación referenciada por la fase.

Tratala como una entrega completa, no como una sucesión de pequeñas tareas. Tenés autonomía para resolver decisiones técnicas menores mientras respetes las decisiones arquitectónicas y de producto existentes.

No inventes ni modifiques reglas del juego. La fuente normativa es docs/game/FUNCTIONAL_SPEC.md.

No hagas commits, push, ramas ni operaciones destructivas de Git.

No avances a la Fase 2. Al terminar la Fase 1, dejá todo ejecutable y verificable, actualizá PROJECT_STATUS.md y presentame:
- resumen de lo implementado;
- comandos para ejecutar y verificar;
- tests relevantes ejecutados;
- checklist concreto de testing manual;
- cualquier decisión importante tomada;
- cualquier limitación real pendiente.
```
