# Brief de arte — Baraja española

## Objetivo

Las cartas deben conservar el **aspecto inmediatamente reconocible de una baraja española tradicional**.

El usuario no busca una reinterpretación futurista ni símbolos minimalistas irreconocibles.

## Estructura

Palos:

- Oros;
- Copas;
- Espadas;
- Bastos.

Rangos posibles:

- 1–12;
- el mazo de 40 omite 8 y 9.

## Lenguaje visual

Conservar:

- fondo marfil/blanco cálido;
- ilustración central tradicional;
- número/rango claramente reconocible;
- composición simétrica cuando corresponda;
- figuras 10/11/12 inspiradas en la convención Sota/Caballo/Rey;
- bordes ornamentales discretos;
- símbolos de palos tradicionales.

## Restricción de propiedad intelectual

“Aspecto original/tradicional” **no significa copiar píxel por píxel una baraja comercial**.

Crear arte propio que respete el vocabulario visual histórico de la baraja española o usar un set con licencia inequívoca.

No incluir marcas comerciales de fabricantes.

## Legibilidad en juego

Las cartas deben funcionar en tamaños pequeños.

Requisitos:

- rango identificable sin abrir zoom;
- palo reconocible por forma además de color;
- figuras no deben confundir 10/11/12;
- dorso claramente distinto del frente;
- contraste suficiente sobre la mesa de madera.

## Dorso

Diseño propio, repetitivo y tradicional. Puede incorporar sutilmente una mosca como elemento gráfico si no vuelve obvio el frente/dorso ni rompe el estilo.

## Formato técnico

Preferir assets vectoriales o raster de alta resolución con una canalización que produzca texturas nítidas para Pixi.

No depender de fuentes/icon fonts para dibujar cartas durante gameplay si compromete consistencia.

## Estados visuales

La carta puede necesitar:

- normal;
- hover;
- seleccionada para cambio;
- sutil indicación de legalidad/recomendación;
- disabled únicamente para acciones realmente imposibles de UI, no para Palito.

La indicación de “jugada reglamentariamente legal” debe ser discreta. No pintar la mitad de la pantalla en verde/rojo.
